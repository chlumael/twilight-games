## 0.9.18

PC 화면 읽기를 네 게임 실제 화면으로 시험해 고침

- PC: 림버스 추출 화면을 PC에서 알아보지 못해 뽑기(이상 N/200)를 세지 못하던 것 고침
- PC: 재화 칸 읽기를 윈도우 글자 인식으로 실제 시험해 고침 — 원신 원석·인연, 명방 합성옥·오리지늄, 엔드필드 오로베릴·교환 칸·허가증·천장 줄 모두 맞게 읽음(칸을 크게 키우고, 바탕을 흰색으로 지우고, 붙은 숫자 사이를 벌려 읽음)
- PC: 원신 캐릭터·무기 기원, 엔드필드 한정·재구축·무기고, 명방 헤드헌팅, 림버스 추출 화면은 재화 칸만 잘라 읽어 더 빠르고 정확하게. 못 읽은 칸은 화면 전체 글자로 채움
- PC: 숫자 옆에 글자가 붙어 읽히면(예: S8414) 틀린 값으로 보고 버림(림버스 광기는 아직 자주 못 읽음 — 뽑기 세기에는 영향 없음)
- PC: 화면 읽기가 훨씬 빨라짐
- PC: 버전 번호가 같아도 고친 설치 파일이 새로 올라오면 켤 때 알려 주고, "업데이트" 한 번으로 받아 설치함
- PC: 설정 "화면 공유"에서 디스코드 화면 공유·방송에 이 창이 보이게 할 수 있음(기본은 안 보임)
- PC: 실행 파일 이름으로 못 잡는 게임도 창 이름이 게임 이름이면 알아봄. 설정 "게임 감지"에 방금 앞에 있던 프로그램 이름을 보여 줌
- 림버스 확인 창: 실제 휴대폰 글자에 맞춤("추출 10회 티켓" 어순, 신규 배너의 긴 이름). 취소하면 줄였던 티켓 수도 되돌림
- 림버스 홈: 가운데 큰 숫자를 "이상" 개수로 바꿈(전에는 000 이후 횟수라 000이 나오면 이상이 0이 된 것처럼 보였음). 000 이후 횟수는 옆에 작게
- 최고 등급 기록 목록: 큰 숫자를 "배너 몇 번째" 대신 "몇 뽑 만에(0스택부터)"로. 픽뚫 뒤에 얻은 픽업은 "픽업까지 N뽑"도 보여 줌. 내 통계에 "픽업 1개당 평균" 추가
- 다른 창(디스코드 오버레이 등)이 게임의 재화 숫자를 가리면 잘못 읽을 수 있으니 숫자 위에 창을 두지 마세요

## 0.9.17

림버스 자동 기록 개선
- 추출 확인 창("광기 1300을 소비하여…")이 뜰 때마다 바로 기록합니다. 결과 화면에서 "재추출"로 연속으로 뽑아도 셉니다. 티켓으로 뽑으면 직접 넣어 둔 티켓 수도 줄어듭니다
- 추출 화면의 "이상 N/200" 숫자로 한 번 더 맞춰 봅니다. 확인 창을 놓친 뽑기는 채우고, 취소한 것은 지웁니다. 다른 배너 뽑기는 섞이지 않습니다. 이상 200개 교환도 기록합니다
- 20회 넘게 몰아 뽑으면 추출 이력에 안 남는 부분을 알려 줍니다
- 추출 이력: 수감자 이름이 잘못 읽힌 줄도 인격 이름으로 찾고, E.G.O 등급(ZAYIN·TETH 등) 줄도 알아봅니다. 너무 빨리 넘겨 중간을 놓치면 알려 줍니다

화면 읽기
- 뽑는 중(뽑기 버튼·확인 창·결과 화면이 보일 때)에는 0.3초마다 읽어 확인 창을 바로 눌러도 덜 놓칩니다. 뽑기 화면을 떠나면 30초 뒤 원래 간격으로 돌아갑니다

새 기능

- 명일방주: 일반 배너끼리 확률 상승 횟수가 이어짐, 단일 픽업 150회·더블 픽업 150/300회, 한정 300회 증정, 콜라보 120회마다 확정
