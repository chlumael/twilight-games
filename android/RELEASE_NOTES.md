## 0.9.16

새 기능
- 게임 아이콘: 위쪽 게임 줄, 달력, 내 통계, 친구, 설정의 '내 게임'에 각 게임의 공식 앱 아이콘이 나옵니다(전에는 재화 그림)
- 게임 순서: 설정 → 내 게임에서 ▲▼로 순서를 바꾸면 게임 줄·달력·통계·친구가 그 순서로 나옵니다

고친 것
- 친구 탭: 아직 아무도 공유하지 않은 게임을 고르면 화면이 비고 게임 고르기 줄까지 사라지던 문제

## 0.9.15

고친 것
- 배너 그림이 잘리던 문제: 게임마다 다른 그림 비율 그대로 보여 줍니다(원신 기원 그림의 양옆이 잘렸음)
- 배너 그림 화질을 높이고, 림버스 배너에 다른 배너 그림이 붙던 문제를 고쳤습니다(앱 업데이트 없이 이미 반영)

## 0.9.14

새 기능
- 캐릭터·무기 아이콘과 배너 그림: 홈 기록·이름 고르기, 배너 자세히, 달력, 통계, 친구 화면에 나옵니다(새 캐릭터는 앱 업데이트 없이 추가)
- 기록 고치기: 홈의 최고 등급 기록 줄을 누르면 몇 번째·이름·픽업/픽뚫을 고치거나 그 기록 하나만 지울 수 있습니다(다른 기록의 번째는 그대로). 4개보다 많으면 "전체 보기"
- 친구 탭을 그룹 없이 한 곳에: 참여한 사람 모두의 전체 통계(게임별 인원·평균·픽업 성공·내 등수)와 운 순위. 친구 탭의 "나도 참여하기"로 바로 참여
- 설정 → 테마: 원하는 게임 테마로 고정하면 모든 화면에 적용(홈에서 게임을 바꿔도 유지)

화면 정리
- 아래 탭을 홈·달력·내 통계·친구·설정으로. "확인" 탭 대신 확인할 것이 있을 때만 홈 맨 위에 "확인할 것 N개" 줄이 나옵니다(화면 읽기 상태는 설정 맨 아래)
- 달력·내 통계·친구에서는 위쪽 게임 줄을 숨김. 달력은 처음부터 내 게임 전부

고친 것
- 엔드필드 무기고: 몇 번째 입력이 1·11·21…만 되던 문제. 이제 10·20·30…으로 오르고, 37처럼 넣으면 그 10회 묶음의 끝(40번째)으로 기록

## 0.9.13

새 기능
- 친구 공유: 설정 → 친구 공유에서 그룹을 만들거나 초대 코드로 참가하면, 통계 → 친구에서 서로의 운 순위와 최근 최고 등급을 봅니다(닉네임과 뽑기 요약만 공유, 재화·이메일은 안 올라감)
- 통계를 한 화면에: 맨 위 게임별 요약, 아래 게임마다 종류별 표(뽑기·최고 등급·평균·픽업·운). 자세한 내용은 "자세히"로
- 설정에 "계정 삭제"(서버 기록과 계정을 지움)와 "개인정보 처리 방침"

고친 것
- 명일방주 교환: 오래된 한정 200장, 5성 75장 교환도 기록. 배너가 끝나면 남은 계약이 파라미터 모델로 바뀌는 수를 표시(림버스는 남은 이상 → 끈)
- 명일방주 가챠 기록 반영: 배너 이름으로 한정·콜라보·일반을 자동으로 골라 둠
- 달력의 외부 행사: 공지에 적힌 행사 날짜로 표시

## 0.9.12

새 기능
- 달력: 픽업·복각 기간, 게임 안 이벤트, 버전 시작·끝, 외부 행사를 날짜별로 봅니다. 콜라보 카페 같은 내 일정도 직접 넣을 수 있어요
- 설정 → 내 게임: 하는 게임만 골라 위쪽 게임 줄과 달력에 보이게
- 예측: "일일·주간 과제 + 월정액"으로 목표일까지 모이는 재화를 계산합니다. 목표일은 자유, 월정액은 켜고 끄기만

화면 정리
- 화면 이동은 아래 탭 5개(홈·달력·통계·확인·설정)로
- 재화 칸 줄 맞춤, "가능 횟수" 설명을 한 줄로, 긴 설명 문장 정리
- 최고 등급 이름은 누르는 단추로 고르고, 적은 글자로 걸러집니다(그 배너에서 나올 수 있는 이름만)

게임 규칙 (공식 공지·게임 데이터 기준)
- 엔드필드: 픽뚫로 나올 수 있는 6성과 언제까지 나오는지 표시, 긴급 모집(무료) 6성 따로 기록, 한정 배너가 바뀌면 배너 전용 허가증 정리(60회 정보서 10장 지급), 오퍼레이터를 뽑으면 무기고 징표 지급
- 엔드필드 무기 배너: 함께 열린 무기고 신청을 모두 표시(지금은 유영·월영·전옥), 상시 무기 배너는 뺌, 이름 후보는 그 배너의 6성 무기
- 원신: 「별빛 포착」(픽뚫 뒤 확정 픽업이 3번 이어지면 다음 5성 픽업 확정), 무기 기원 픽업 75%, "집록"을 공식 이름 「묶음」으로
- 명일방주: 일반 배너끼리 확률 상승 횟수가 이어짐, 단일 픽업 150회·더블 픽업 150/300회, 한정 300회 증정, 콜라보 120회마다 확정

## 0.9.11

- 직접 입력의 숫자가 "이 배너에서 몇 번째"(배너 누적)로 바뀌었습니다. 58 → 92 → 120처럼 순서대로 넣으면 차이만큼만 더합니다
- "횟수만" 체크: 최고 등급 없이 이 배너에서 몇 번째까지 뽑았는지만 맞추기
- 최고 등급 기록의 큰 숫자를 배너 누적 "n번째"로 표시 (옆에 작게 걸린 횟수)
- 통계 → 기록 정리에 "○○ 처음부터 다시" 추가 (그 종류의 기록과 시작 상태 비우기)
- 공식 기록을 반영할 때 직접 입력 기록이 있으면 "확인"에서 바꿀지 고릅니다 (두 번 세기 방지)
- 가능 횟수에 파생 오리지늄·오리지늄 포함, 엔드필드 허가증을 공식 이름으로
- 엔드필드 무기고 횟수는 항상 10의 배수, 한정/재구축 화면은 픽업 이름으로 확인한 때만 천장 반영
- 설정·예측 칸 이름 정리, 운 등급은 절반보다 나쁘면 "운 하위 N%"
