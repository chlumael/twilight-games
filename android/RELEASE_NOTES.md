## 0.9.11

- 직접 입력의 숫자가 "이 배너에서 몇 번째"(배너 누적)로 바뀌었습니다. 58 → 92 → 120처럼 순서대로 넣으면 차이만큼만 더합니다
- "횟수만" 체크: 최고 등급 없이 이 배너에서 몇 번째까지 뽑았는지만 맞추기
- 최고 등급 기록의 큰 숫자를 배너 누적 "n번째"로 표시 (옆에 작게 걸린 횟수)
- 통계 → 기록 정리에 "○○ 처음부터 다시" 추가 (그 종류의 기록과 시작 상태 비우기)
- 공식 기록을 반영할 때 직접 입력 기록이 있으면 "확인"에서 바꿀지 고릅니다 (두 번 세기 방지)
- 가능 횟수에 파생 오리지늄·오리지늄 포함, 엔드필드 허가증을 공식 이름으로
- 엔드필드 무기고 횟수는 항상 10의 배수, 한정/재구축 화면은 픽업 이름으로 확인한 때만 천장 반영
- 설정·예측 칸 이름 정리, 운 등급은 절반보다 나쁘면 "운 하위 N%"
