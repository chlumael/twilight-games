## 0.9.12

새 기능
- 달력: 픽업·복각 기간, 게임 안 이벤트, 버전 시작·끝, 외부 행사를 날짜별로 봅니다. 콜라보 카페 같은 내 일정도 직접 넣을 수 있어요
- 설정 → 내 게임: 하는 게임만 골라 위쪽 게임 줄과 달력에 보이게
- 예측: "일일·주간 과제 + 월정액"으로 목표일까지 모이는 재화를 계산합니다. 목표일은 자유, 월정액은 켜고 끄기만

화면 정리
- 화면 이동은 아래 탭 5개(홈·달력·통계·확인·설정)로
- 재화 칸 줄 맞춤, "가능 횟수" 설명을 한 줄로, 긴 설명 문장 정리
- 최고 등급 이름은 누르는 단추로 고르고, 적은 글자로 걸러집니다(그 배너에서 나올 수 있는 이름만)

게임 규칙 (공식 공지·게임 데이터 기준)
- 엔드필드: 픽뚫로 나올 수 있는 6성과 언제까지 나오는지 표시, 긴급 모집(무료) 6성 따로 기록, 한정 배너가 바뀌면 배너 전용 허가증 정리(60회 정보서 10장 지급), 오퍼레이터를 뽑으면 무기고 징표 지급
- 엔드필드 무기 배너: 함께 열린 무기고 신청을 모두 표시(지금은 유영·월영·전옥), 상시 무기 배너는 뺌, 이름 후보는 그 배너의 6성 무기
- 원신: 「별빛 포착」(픽뚫 뒤 확정 픽업이 3번 이어지면 다음 5성 픽업 확정), 무기 기원 픽업 75%, "집록"을 공식 이름 「묶음」으로
- 명일방주: 일반 배너끼리 확률 상승 횟수가 이어짐, 단일 픽업 150회·더블 픽업 150/300회, 한정 300회 증정, 콜라보 120회마다 확정

## 0.9.11

- 직접 입력의 숫자가 "이 배너에서 몇 번째"(배너 누적)로 바뀌었습니다. 58 → 92 → 120처럼 순서대로 넣으면 차이만큼만 더합니다
- "횟수만" 체크: 최고 등급 없이 이 배너에서 몇 번째까지 뽑았는지만 맞추기
- 최고 등급 기록의 큰 숫자를 배너 누적 "n번째"로 표시 (옆에 작게 걸린 횟수)
- 통계 → 기록 정리에 "○○ 처음부터 다시" 추가 (그 종류의 기록과 시작 상태 비우기)
- 공식 기록을 반영할 때 직접 입력 기록이 있으면 "확인"에서 바꿀지 고릅니다 (두 번 세기 방지)
- 가능 횟수에 파생 오리지늄·오리지늄 포함, 엔드필드 허가증을 공식 이름으로
- 엔드필드 무기고 횟수는 항상 10의 배수, 한정/재구축 화면은 픽업 이름으로 확인한 때만 천장 반영
- 설정·예측 칸 이름 정리, 운 등급은 절반보다 나쁘면 "운 하위 N%"
