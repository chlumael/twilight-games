# 배포 전 확인 목록

친구 배포·공개 배포 전에 **사용자가 직접** 해야 하는 것과, 코드로 준비해 둔 것. (2026-11-26 작성)

## 사용자가 할 일

| 순서 | 할 일 | 어디서 | 왜 |
|---|---|---|---|
| 1 ✅ | **보안 규칙 게시**(2026-11-27 완료): 저장소의 `firestore.rules` 내용을 그대로 붙여 넣고 "게시" | Firebase 콘솔 → Firestore Database → 규칙 | 친구 공유 그룹(groups) 규칙이 추가됨. 게시 전에는 친구 공유가 "권한 없음"으로 실패한다 |
| 2 ✅ | **구글 로그인 공개 상태 확인**(2026-11-27 확인: 프로덕션 단계, 사용자 유형 외부 — 할 것 없음): "게시 상태"가 "테스트"면 "프로덕션으로 푸시" | Google Cloud 콘솔 → API 및 서비스 → OAuth 동의 화면 (프로젝트 twilight-games) | 테스트 상태면 등록한 테스트 사용자만 로그인된다. 화면의 "OAuth 사용자 한도 100명"은 민감한 권한을 쓰는 앱에만 걸리는 것으로, 이메일·프로필만 쓰는 이 앱과는 상관없음(구글 안내문 기준) |
| 3 | **사용량 확인**: 하루 읽기·쓰기 횟수 | Firebase 콘솔 → Firestore → 사용량 | 무료 요금제에는 하루 한도가 있다(정확한 숫자는 콘솔에서 확인). 친구 몇 명이면 넉넉할 것으로 봄(추정) |
| 4 | **설치 안내 공유**: 웹앱 주소 뒤에 `/install.html` | `https://chlumael.github.io/twilight-games/install.html` | 친구에게 이 주소 하나만 보내면 됨 |

## 코드로 준비한 것

| 항목 | 상태 |
|---|---|
| 친구 공유·운 순위 (DESIGN.md §8.5) | 구현. 보안 규칙은 에뮬레이터로 시험하지 못함(이 환경에서 실행이 막힘) → 1번 게시 후 실제로 그룹 만들기·참가를 두 계정으로 확인 필요 |
| 계정 삭제 (서버 기록·공유 요약·로그인 계정) | 구현. 최근 로그인한 경우에만 됨 |
| 개인정보 처리 방침 | `public/privacy.html`, 앱 설정에서 펼쳐 보기 |
| 설치 안내 페이지 | `public/install.html` |
| 서명 키 | **바꾸지 않는다.** 지금 키는 이 프로젝트 전용으로 만든 키(저장소 비밀값에만 있음)라 그대로 써도 된다. 바꾸면 모든 사용자가 지우고 다시 설치해야 해서 기록이 날아갈 위험이 있다 |

## 공개 배포 때 더 볼 것

- 문의 창구(메일 또는 오픈채팅)를 개인정보 처리 방침 7번에 적기
- 게임 아이콘: 문제 제기가 오면 바로 뺄 수 있게(아이콘이 없으면 기본 모양으로 보이도록 이미 처리돼 있음)
- 버전: 정식 배포 전까지 0.9.x 유지(사용자 2026-11-26)
