황혼 게임즈 설치 안내

원신 · 명일방주 · 명일방주: 엔드필드 · 림버스 컴퍼니의 뽑기 기록과 천장을 관리하는 앱입니다. 무료이고 광고가 없습니다.

안드로이드 휴대폰

최신 버전 받기
  1. 열린 페이지의 "Assets"에서 twilight-games-버전.apk를 누릅니다.
  2. 받은 파일을 엽니다. "출처를 알 수 없는 앱" 안내가 나오면 설정 → 이 출처 허용을 켜고 돌아와 설치합니다.
  3. 플레이 스토어 앱이 아니라서 "안전하지 않은 앱" 경고가 나올 수 있습니다. "무시하고 설치"를 고르면 됩니다.
  4. 다음부터는 앱 안에서 업데이트 알림이 뜹니다.

윈도우 PC

PC 설치 파일 받기
  1. 받은 파일을 실행합니다. "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 누릅니다(서명 인증서가 없는 개인 제작 프로그램이라 나오는 안내입니다).
  2. 다음부터는 프로그램을 켤 때 업데이트 알림이 뜹니다.

브라우저로 쓰기

웹앱 열기

설치 없이 쓸 수 있지만 화면 읽기는 안 됩니다. 기록을 남기려면 로그인하세요.

친구와 같이 쓰기

  1. 설정 → 트래커 계정에서 구글 로그인합니다.
  2. 설정 → 친구 공유에서 닉네임을 적고 "내 요약 공유하기"를 켭니다.
  3. 한 사람이 "그룹 만들기"를 하고 초대 코드 10자리를 알려 주면, 나머지는 "코드로 참가"에 넣습니다.
  4. 통계 → 친구에서 서로의 기록과 운 순위를 봅니다.

공유되는 것은 닉네임과 뽑기 요약뿐입니다. 자세한 내용은 개인정보 처리 방침.
